# Code of Conduct

## Our commitment

This repository is intended to be a constructive learning environment for people exploring machine learning and deep learning.

Participants are expected to communicate with respect, assume good faith, and focus criticism on ideas, code, experiments, and documentation rather than people.

## Expected behavior

- Be respectful and professional.
- Give actionable technical feedback.
- Welcome questions from learners at different levels.
- Credit sources, datasets, and prior work where appropriate.
- Keep discussions relevant to the repository.

## Unacceptable behavior

Harassment, discrimination, personal attacks, deliberate disruption, doxxing, spam, or other inappropriate conduct is not acceptable.

## Enforcement

Project maintainers may remove, edit, or decline contributions that violate this code of conduct. Serious or repeated violations may result in restricted participation.

For concerns, open an issue with enough context for the maintainer to understand what happened.
