# Security Policy

## Scope

This repository is primarily an educational collection of notebooks and datasets.

Please do not publish secrets, API keys, passwords, tokens, private credentials, or other sensitive information in issues, pull requests, notebooks, commits, or datasets.

## Reporting a security issue

If you discover a genuine security vulnerability involving the repository or its automation, please avoid publicly posting sensitive exploit details.

Open a private security report through GitHub if private vulnerability reporting is available for the repository. Otherwise, contact the repository owner through their GitHub profile and provide:

- a concise description;
- affected file or workflow;
- reproduction steps;
- potential impact;
- a suggested mitigation, if known.

For ordinary notebook bugs or dependency problems, use a normal GitHub issue instead.
